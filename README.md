#Описание проекта:
Данный проект помогает пользователю оценить рынок жилья города Мельбурн с имеющейся базой данных. Пользователь, воспользовавшись имеющимся функционалом, может увидеть качественные визуализации,
а также взаимосвязь между такими параметрами как площадь жилья, площадь участка, районом города, ценой и другими немаловажными параметрами.
